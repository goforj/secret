# Driver artwork

[Dashboard Icons](https://github.com/homarr-labs/dashboard-icons), SVG files
`aws.svg`, `microsoft-azure.svg`, `google-cloud.svg`, and `hashicorp-vault.svg`.
Retrieved 2026-11-09. The upstream collection is Apache-2.0 licensed; logos remain
trademarks of their respective owners. Source artwork is embedded into generated
badges so GitHub does not fetch nested third-party assets.

The mounted-file and feature icons are original repository-owned SVG paths defined
in `docs/gen/readme.go`, distributed under this repository's MIT license.
